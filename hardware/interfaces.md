# Core 电气接口定义（草案 0.1）

Core 对外只有三个电气接口。它们在 EVT-B 冻结；冻结前可以改，改动要更新本文件。

电平约定：除特别说明外，逻辑电平为 3.3 V（Core 主板上由电平转换保证，与 SoC 的 IO 电压无关）。方向以 Core 为参照。

## 1. OAC Link（Core ↔ Dock）

10 针镀金焊盘，底座侧为弹簧针，磁吸对位。焊盘图形和位置待结构设计确定。

| 针 | 信号 | 方向 | 电气特性 |
|---|---|---|---|
| 1 | `VEXT_5V` | 入 | 4.5–5.5 V，底座需能提供 ≥ 2 A；Core 侧有 TVS 和防倒灌 |
| 2 | `GND` | — | |
| 3 | `USB_DP` | 双向 | USB 2.0，Core 为主机；仅在底座声明需要时才对外供电 |
| 4 | `USB_DM` | 双向 | |
| 5 | `UART_TX` | 出 | 默认 115200 8N1，可协商到 1 Mbps |
| 6 | `UART_RX` | 入 | 内部上拉 |
| 7 | `TRIG_IN` | 入 | 外部触发或 PPS；上升沿有效；内部 100 kΩ 下拉；耐压 5 V |
| 8 | `SYNC_OUT` | 出 | 帧同步脉冲，每帧一个，来自传感器 XVS |
| 9 | `DOCK_ID` | 双向 | 1-Wire，Core 侧 2.2 kΩ 上拉到常开电源轨（3.0 V） |
| 10 | `GND` | — | |

说明：

- Core 不通过触点向底座输出电源。需要供电的底座自带电源，或从 USB 口的 VBUS 取电（待定：是否增加一个受控的 5 V 输出针）。
- `DOCK_ID` 上的 EEPROM 要能在 3.0 V 上拉下工作。内容格式（底座型号、硬件版本、默认场景档名、是否需要 USB）在 `proto/oac/v1/link.proto` 中定义，尚未编写。
- 触点上传 USB 2.0 高速信号能否稳定，需要用伴随板实测；不稳定就降为全速。

## 2. 电池触点（Core ↔ Shell 电池仓）

| 信号 | 说明 |
|---|---|
| `BAT+` | 1S 锂电池正极，3.0–4.45 V，持续电流 ≥ 2 A |
| `BAT-` | 负极 / 地 |
| `TS` | 电池包内 NTC（预期 10 kΩ）到 `BAT-`；没有 NTC 的电池由固件按「无法测温」处理，降低充电电流 |
| `ID` | 电池识别；Core 侧 100 kΩ 上拉到 3.0 V，MCU 用 ADC 读取 |

触点的物理顺序、间距和电池仓尺寸，要等标准电池（GoPro HERO9–12 型）拆解实测后确定。

充电电压规则：无法识别电池时，充电截止电压用充电芯片的默认值 4.208 V；只有识别出已验证的高压电芯，固件才把截止电压提高。

## 3. Shell 连接器（Core ↔ 屏 / 按键）

两个 FPC 连接器，尚未定义针脚。预期内容：

| 连接器 | 信号 |
|---|---|
| 主屏 | MIPI DSI 或 RGB、背光、屏供电、复位 |
| 按键与前屏 | 3 个按键、仓门开关 `BAT_DOOR_N`、前屏 SPI、振动马达、状态 LED、常开电源轨 |

主屏接口在选定屏和核心板之后定义。

# P0 伴随板 PCB 设计约束

PCB 布局尚未进行。本文件是给布局工程师的输入。

## 板子

| 项目 | 取值 |
|---|---|
| 层数 | 4 层：信号 / 地 / 电源 / 信号 |
| 板厚 | 1.6 mm，1 oz 铜 |
| 尺寸 | 约 60 × 45 mm，不追求小，方便探针和飞线 |
| 最小线宽 / 间距 | 0.15 / 0.15 mm（由 0.5 mm 间距的 QFN 和 LGA 决定） |
| 安装孔 | 4 × M2.5，其中两个靠近 IMU（见下） |

## 分区

```text
┌──────────────────────────────────────────────┐
│ [USB-C] [充电芯片 + 电感]      [超级电容]      │  ← 功率区
│ [电池触点] [电量计] [检流电阻 + 测试点]        │
├──────────────────────────────────────────────┤
│ [LDO] [比较器] [加速度计] [麦克风]  [MCU 排针] │  ← 常开域
├──────────────────────────────────────────────┤
│ [IMU]            [OAC Link 触点]   [SoC 排针]  │  ← 主电源域信号
└──────────────────────────────────────────────┘
```

## 充电芯片（U1）

- 输入电容、PMID 电容、电感、SYS 电容组成的功率回路面积要最小，全部放在顶层，紧贴芯片。
- `SW` 节点铜皮尽量小；下方的地层保持完整，不走其他信号。
- 散热焊盘打 ≥ 9 个过孔到地层。
- `VBUS_IN`、`VSYS`、`VBAT` 走线按 3 A 设计，线宽 ≥ 1.5 mm 或铺铜。
- 电感离 IMU 和麦克风 ≥ 15 mm。

## 检流电阻（R 20 mΩ × 2）

- 开尔文连接：测试点从电阻焊盘内侧引出，不与功率走线共用铜皮。

## IMU（U6）

- 放在板上机械最稳的位置，靠近安装孔，远离板边和连接器（插拔应力会带来零偏变化）。
- 器件正下方所有层不走线、不打过孔；周围 2 mm 内不放其他器件。
- 焊盘走线对称引出，避免回流焊时受力不均。
- 远离电感、马达和超级电容。
- 在丝印上标出 X / Y / Z 轴方向。
- SPI 走线 ≤ 50 mm，`IMU_FSYNC` 远离 `CHG_SW`。

## 加速度计（U5）与麦克风（MK1）

- 加速度计的机械要求同 IMU，可以略放松。
- 麦克风是底部进音：PCB 上开进音孔（孔径按数据手册），孔周围不放过孔和丝印，背面留出声腔空间。
- 麦克风离马达尽量远。

## OAC Link（J5）

- 焊盘图形等结构设计确定；伴随板上先用 2.54 mm 间距的 10 针排针孔代替，方便接飞线和弹簧针测试夹具。
- `LINK_USB_DP / DM` 按 90 Ω 差分走线，等长，全程参考地层，ESD 器件贴近触点。经排针传高速 USB 本身不理想，这里只做能不能用的评估。
- `VEXT_5V` 线宽按 2 A。

## 常开域

- `AON_3V0` 上的漏电直接决定待机时长：这个区域不用助焊剂残留多的工艺，测试点不要过多。
- 1 MΩ 级的分压节点（`PF_DIV`、`BAT_DOOR_N`）走线短，远离开关节点。

## 丝印与测试

- 所有测试点、跳线、排针的信号名印在板上。
- 两个排针的 1 脚有明确标记。
